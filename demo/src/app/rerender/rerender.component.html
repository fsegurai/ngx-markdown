Re-render

In some situations, you might need to re-render markdown after making changes. If you've updated the text this would be done automatically, however if the changes are internal to the library such as rendering options, you will need to inform the `MarkdownService` that it needs to update. To do so, inject the `MarkdownService` and call the `reload()` function as shown below. ```typescript import { inject } from '@angular/core'; import { MarkdownService } from '@fsegurai/ngx-markdown'; private readonly markdownService = inject(MarkdownService); update() { this.markdownService.reload(); } ``` Changing a rendering option input (`inline`, `emoji`, `clipboard`, `katex`, `mermaid`, the Prism plugin inputs...) does not re-render either: it applies to the next `data`/`src` change or `reload()`. `reload()` also renders the content transcluded between the `<markdown>` tags again. The exception is `mermaidOptions`: changing it re-renders the Mermaid diagrams alone, as `markdownService.rerenderMermaid(element, { mermaidOptions })` does (see the [Mermaid plugin](/plugins#mermaid)).
