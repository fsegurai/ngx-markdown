Marked Extended

Setup

The [`@fsegurai/marked-extended-*`](https://github.com/fsegurai/marked-extensions) packages plug in with `withMarkedExtended(features)`: each feature passes the Marked extension of a package and its browser runtime (`attachX`). This page provides them in its own `MarkdownService` and keeps **Angular's sanitizer on**: the markup of the packages survives it, and the runtimes restore the behaviour in the browser. ```typescript import markedExtendedTabs, { attachTabs } from '@fsegurai/marked-extended-tabs'; import markedExtendedCode, { attachCode, wrapLines } from '@fsegurai/marked-extended-code'; provideMarkdown({ plugins: [ withPrism(), withMarkedExtended([ { name: 'tabs', extension: markedExtendedTabs(), attach: attachTabs }, { name: 'code', extension: markedExtendedCode(), attach: attachCode, options: { lineClasses: false }, afterHighlight: wrapLines }, ]), ], }); ``` The `marked-extended:*` events of the content are emitted by the `(extendedEvent)` output: interact with the examples below and watch the events log. ```html <markdown [src]="'tabs.md'" (extendedEvent)="onExtendedEvent($event)"></markdown> ```
