# Getting Started

Three steps take you from zero to a configured Markdown renderer.

1. [Installation](installation.md) - add the library, `marked`, and only the optional peers you use.
2. [Quick Start](quick-start.md) - render Markdown with `<markdown>` or the `markdown` pipe.
3. [Configuration](configuration.md) - set options and plugins once with `provideMarkdown()`.
