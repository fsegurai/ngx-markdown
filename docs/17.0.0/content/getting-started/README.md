# Getting Started

Three steps take you from zero to a configured Markdown renderer.

1. [Installation](installation.md) - add the library, `marked`, and the plugin scripts you use.
2. [Quick Start](quick-start.md) - call `provideMarkdown()` and render Markdown with `<markdown>` or the `markdown` pipe.
3. [Configuration](configuration.md) - set marked options, plugin defaults and sanitizing once.
